# 内置文件查看器设计

**日期：** 2026-08-06

## 目标

在星轨项目管理系统中增加应用内查看能力，覆盖 PDF、Word 文档和 STP/STEP 三维模型，并同时适配桌面浏览器、PWA 和 Android WebView。查看器使用现有登录态和文件权限，不把业务逻辑绑定到 Windows 桌面壳。

本次明确不支持 Parasolid XT（.x_t、.x_b）格式。

## 用户体验

用户在项目文件或图纸列表中点击支持的文件后，系统在现有模态框中打开内置查看器，不跳转外部浏览器或系统应用。

PDF 查看器提供页码导航、缩放、旋转和适宽显示。Word 查看器对 .docx 渲染标题、段落、表格、图片和基础文字样式，并支持连续滚动。旧版 .doc 不在线解析，显示明确提示并提供下载原文件。

STP/STEP 查看器提供实体模型的旋转、平移、缩放、适合窗口和重置视角，并提供实体/线框显示切换。三维查看器在桌面端使用大模态框，在手机端占满可用视口并保留触摸手势。

所有查看器提供关闭和下载操作。文件不存在、格式不支持、解析失败或浏览器能力不足时显示可理解的错误信息，并保留下载入口。

## 架构

### 文件服务

继续使用现有登录保护的文件预览和下载路由。预览响应保持内联展示所需的 MIME 类型，并拒绝不存在或已丢失的文件。Word 和 CAD 解析器通过现有文件 ID 获取数据，不暴露新的未授权文件路径。

### 文档查看器

PDF 使用随项目静态发布的 PDF.js 资源，在应用内渲染页面，避免依赖 Android WebView 的系统 PDF 能力。DOCX 使用浏览器端解析库转换为受限 HTML，再放入隔离的查看区域；渲染结果禁止执行脚本。.doc 只提供下载提示。

### CAD 查看器

STP/STEP 使用浏览器端 OpenCascade WebAssembly 解析几何数据，使用 Three.js 负责场景、相机、灯光、触摸和鼠标交互。解析器和渲染器放在静态资源层，业务代码只负责文件 URL、查看器生命周期和错误状态。

查看器统一暴露 openFileViewer、closeFileViewer、resetFileViewer 和 downloadFileViewerSource 接口。不同格式的渲染器通过文件类型分派，不修改项目、权限、上传和删除业务流程。

## 响应式设计

桌面端查看器模态框最大化可用空间，工具栏固定在顶部，内容区域独立滚动或缩放。手机端使用全屏模态框，按钮采用稳定尺寸，操作区避让安全区，模型画布使用触摸手势；文档区域不使用固定宽度，避免横向溢出。

## 错误与降级

- .pdf、.docx、.stp、.step 使用对应内置查看器。
- .doc 显示“旧版 Word 暂不支持在线预览”，提供下载。
- XT 文件显示“不支持 XT 格式”，提供下载。
- 解析器加载失败时显示“查看器资源加载失败”，提供重试和下载。
- 文件过大、格式损坏或解析异常时不阻塞页面导航，关闭查看器即可回到原列表。

## 版本与发布

本功能发布为 1.0.6，同步更新根目录 VERSION、网页版本资源、PWA manifest/service worker 和 Android manifest versionCode。服务器部署网页和依赖后重启服务，重新构建并生成星轨_1.0.6.apk。

## 测试标准

后端测试验证支持格式分派、登录保护、原文件下载兜底和解析失败响应。前端静态测试验证 PDF/DOCX/STP/STEP 进入应用内查看器、DOC/XT 进入降级提示，以及桌面/手机查看器样式存在。构建测试验证版本号和 APK versionCode 同步。发布前运行完整 Python 测试集并检查服务器健康状态。

## 范围外

本次不实现 XT/Parasolid 解析、不实现 Office 在线编辑、不实现 CAD 模型编辑或标注、不更换现有上传和权限模型。
